# ⚙️ Guía de Configuración Local — Proyecto LIA

Esta guía detalla los pasos exactos para configurar el entorno local y ejecutar **LIA** (Learning Intelligence Assistant) usando la arquitectura RAG con modelos locales y Streamlit.

---

## 📋 1. Requisitos Previos

Asegúrate de tener instalados los siguientes componentes en tu máquina (Windows 11):
- **Python 3.11+**
- **[Ollama](https://ollama.com/)** (Para ejecutar los LLMs localmente).
- **[uv](https://docs.astral.sh/uv/)** (Gestor de paquetes y entornos virtuales ultrarrápido).
- **Git** (Para clonar el repositorio).

---

## 🚀 2. Instalación y Configuración del Entorno

Abre tu terminal (PowerShell) y sigue estos pasos:

### Paso 2.1: Clonar el proyecto
```powershell
git clone [https://github.com/tu_usuario/LIA-Colombo-AI.git](https://github.com/tu_usuario/LIA-Colombo-AI.git)
cd LIA-Colombo-AI
